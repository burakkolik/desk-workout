# Desk Workout

An Android app (Flutter) built only for **desk workers**. It covers posture, stretching, eye care, breathing and
nutrition. Every illustration, animation, icon and button is **drawn in code**. The app ships no image assets.

* 36 exercises verified against medical sources (Mayo Clinic, Harvard Health, Cleveland Clinic, NHS, HSS, OSHA,
  AAO). Each one has a keyframe animation of the character, step-by-step instructions, a tip and its source.
* 9 guided programs, plus a workout player with get-ready and rest countdowns, auto-advancing steps, haptics and
  confetti.
* Eye care: a 20-20-20 timer, eye exercises and an annotated ergonomic desk setup illustration.
* Nutrition: an animated water tracker, a caffeine guide (400 mg/day), drawn snack illustrations and habits.
* Progress: daily goal ring, streaks, weekly chart and achievements.
* English + Turkish. The app follows the device language and falls back to English.
* Responsive layout from small phones to large tablets, in portrait and landscape. Phones get a floating bottom
  bar; wide screens get a side rail and two-pane layouts.

## Project structure

```
lib/
  main.dart                  entry point
  app/                       MaterialApp, AppScope (state access), routes
  core/                      shared, feature-agnostic code
    icons/                   hand-drawn icon set (DwIcon)
    l10n/                    context.l10n + LocaleResolver (device language -> fallback EN)
    responsive/              breakpoints, MaxWidth
    storage/                 SharedPreferences wrapper
    theme/                   colours, gradients, typography
    utils/                   formatting
    widgets/                 premium UI kit (GlassCard, GradientButton, ProgressRing, LogoMark…)
  features/
    figure/                  animation engine: Pose, skeleton (FK), IK, MotionClip, painters
    exercises/               domain models, catalog, clips (per body area), library & detail UI
    workout_player/          guided session controller + player / completion screens
    splash/ onboarding/ shell/ home/ eye_care/ nutrition/ progress/ settings/
  l10n/
    arb/app_en.arb           English strings (template)
    arb/app_tr.arb           Turkish strings
    generated/               generated by `flutter gen-l10n`
tool/l10n/                   optional Python source used to keep EN/TR ARB files in sync
assets/icon/app_icon.png     512×512 Play Store icon
assets/store/feature_graphic.png  1024×500 Play Store feature graphic
```

## Adding a new language

1. Copy `lib/l10n/arb/app_en.arb` to `lib/l10n/arb/app_<code>.arb` (for example `app_de.arb`).
2. Set `"@@locale": "<code>"`, translate the values and set `languageNativeName` (for example `Deutsch`).
3. Run `flutter gen-l10n`, or just build.

That is the only step. The language then appears in the language picker automatically, and devices set to that
language start in it.

## Adding an exercise

1. Write a clip in `lib/features/exercises/data/clips/*_clips.dart`. Poses are keyframes of `Pose`, and the IK
   helpers `reachArm` and `reachLeg` place hands and feet on targets.
2. Add `exXxxName`, `exXxxSummary`, `exXxxSteps` (newline separated) and `exXxxTip` to the ARB files.
3. Register the exercise in `exercise_catalog.dart`.

## Dev tools

```bash
flutter analyze
flutter test                                                        # unit + 10 end-to-end smoke tests (5 screen sizes × 2 languages)
RENDER_PREVIEWS=1 flutter test test/dev/figure_preview_test.dart    # every keyframe -> build/previews/*.png
SCREENSHOTS=1 flutter test test/dev/screenshot_test.dart            # real-font screenshots -> build/screens/
GENERATE_ASSETS=1 flutter test test/dev/generate_assets_test.dart   # launcher icons, Play icon, feature graphic
python3 tool/l10n/gen_arb.py && flutter gen-l10n                    # regenerate EN/TR ARB files from tool/l10n
```
